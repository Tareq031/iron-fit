💪 iron-fit — Workout Library

Train with intent. Log every set.

iron-fit is a modern, dark-themed workout library built with Next.js, TypeScript, and Tailwind CSS. It allows users to explore workouts, view exercise details, create a daily workout plan, and save exercises for later.

🛠️ Technologies Used

- Next.js — Application framework and routing
- React.js — Building reusable UI components
- TypeScript — Type-safe development
- Tailwind CSS — Responsive styling
- REST API — Fetching workout data
- React Context API — Managing shared workout state
- localStorage — Persisting workout selections
- React Toastify — Toast notifications

✨ Key Features

1. Workout Library: Browse exercises with images, muscle groups, equipment, and workout statistics.
2. Workout Details: View exercise descriptions, difficulty levels, sets, reps, and step-by-step instructions.
3. Today's Plan: Add exercises to a daily workout plan with a maximum limit of five exercises.
4. Save for Later: Save exercises and manage them separately from the daily plan.
5. Responsive Design: Enjoy a modern dark-themed interface across mobile, tablet, and desktop devices.
